# JUNGOL [8578_또래]
https://jungol.co.kr/problem/8578
- 난이도: 1
- 제한: 시간 2초 / 메모리 1024MB
- 분류: 정렬
- 풀이 날짜: 2026-11-02

## 문제 요약
N개의 자연수 중 두 개를 골랐을 때 차이의 최솟값을 구한다. (N ≤ 200,000)

## 접근 방법
1. 모든 쌍 비교는 약 200억 번 연산으로 시간 초과
2. 정렬하면 a ≤ b ≤ c일 때 c − a ≥ b − a 이므로,
   최솟값은 항상 인접한 두 수 사이에서 나온다
3. 정렬 후 인접 차이의 최솟값을 구한다
   (같은 값이 있으면 자동으로 0이 나옴)

## 복잡도
- 시간: O(N log N)
- 공간: O(N)
